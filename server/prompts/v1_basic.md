# Prompt Version 1: Basic (Naive One-Liner)

## Prompt Template
```
Write a professional cover letter for {{name}} applying for the {{role}} position at {{company}}.
Key skills: {{skills}}.
Make it persuasive and well written.
```

## Characteristics
- **Architecture:** Single-turn raw instruction without role specification.
- **Constraints:** None.
- **Fact Verification:** Completely absent; the model is free to extrapolate or invent past employers, projects, and degree qualifications.
- **Output Mode:** Unstructured text or markdown.
